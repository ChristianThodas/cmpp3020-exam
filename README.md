## Project 2: Intelligent Transit Route Optimizer

## Problem Statement
Build a system that determines the optimal route between two transit stops based on travel time.

## Key Requirements
• Classes: TransitStop, Route, Graph, Optimizer
• Build a weighted graph
• Compute shortest path
• Parallelize route validation or search
• Handle invalid stops and disconnected routes (three exceptions minimum)

## Solution
This is a classic Dijkstra's Algorithm problem, thank you leetcode!
